# Round 0: Kriyan as it is (main at 18441e7)

A planner for one person (here: a university student). Today is the app; phone has three round buttons (Menu, Add, Month), desktop a left rail. Agents (Claude, ChatGPT) read and write the same plan over MCP and a CLI.

## The kinds of thing

| Kind | What it is | Where you make it |
| --- | --- | --- |
| Task | Something to tick off. Title only is required; date, time, length, deadline, repeat, reminders, space, goal, steps, note are optional. | Add (Task) |
| Event | A task you attend (class, meeting). Same editor, one switch. | Add (Event) |
| Repeating task | A task with a rule ("every tue and thu 9am"). Each date is an occurrence. | Add, typed in the sentence |
| Deadline | A field on a task ("Due Fri 6 Nov"). | Task editor |
| Study session | A task that prepares for a test (prepFor). | Agents only |
| Habit | "N times a week", no fixed days or time. Shows as a ring on Today. Missing a day resets nothing. | Add (Habit), or Goals and habits |
| Routine | One block at a set time made of parts (Brush teeth 5 min, Gym 45 min Mon/Wed/Fri). A part can be a habit. | Agents only |
| Goal | A number with a target and date ($, kg, km) or a count of linked tasks. Quick log buttons (+$20). | Goals and habits |
| Focus session | Timed work on a task, counted toward goals. | Focus |
| Space | Coloured container, nests (School > CSC 316). | Menu |
| Note, Steps | Markdown and a checklist inside a task or space. | Task editor |
| Proposal | A task an agent suggested, waiting for Accept. | Agents |

Links: task → goal (picked in the editor). Habit → goal and routine part → habit exist, but only agents can set them. "Gym every mon wed fri" typed as a Habit becomes "3 times a week" and forgets the days.

## How you add things

One sentence in Add: "CSC 316 every tue and thu 10:15 for 1h15 #CSC316". It parses as you type; you pick Task, Event or Habit above it. No day goes to the Inbox. Goals have their own form on Goals and habits.

## Today

- Big day name, week strip, a pull-down summary sentence.
- The day as time blocks from Wake up to Wind down, tinted by space, with dashed free gaps ("1 h 45 free"). Routines sit after Wake up or before Wind down.
- **To fit in**: a checklist card above the day: due today without a time, what's left from this week, and tasks for today without a time. Tick there, or drag onto a free gap; a task with no length asks for one (Kriyan never guesses).
- **From earlier**: one quiet row, "Move to today" / "Pick a day". Older items wait in the Inbox.
- Habits as rings. Review card in the evening; "Close the day" moves what's left to tomorrow.
- Agents can lay out a week; their blocks show as proposals with Accept.

Nothing on Today picks what to do next for you beyond the clock: the blocks you placed and "Now". Unplaced work sits in To fit in for you to choose from.

## The seven scenarios

1. **CSC 316, Tue and Thu 10:15–11:30.** Add, pick Event, type one sentence. Done in one step. Shows as a block both days.
2. **Exam in 2 weeks, study for it.** Add the exam as an event on its day. Study sessions: add tasks yourself on chosen days; linking them to the exam ("7 days left") needs an agent.
3. **Gym 3 times a week, feeding "lose 4 kg".** Add habit "Gym 3 times a week" (ring on Today, no time). Add a number goal "Weigh 72 kg by 1 Mar" on Goals. Linking habit to goal needs an agent. Gym never gets a slot on the day unless you also add tasks.
4. **Morning routine.** Not possible in the app; ask an agent. Once made it's a block after Wake up with parts to tick.
5. **Save $1000 by 31 Dec.** Number goal with $ unit; log +$20 by hand. Nothing on any day asks you to put money aside.
6. **Mom's birthday, 14 Mar.** Task "Mom's birthday every year 14 mar". Reminder 09:00 that day by default.
7. **Buy stamps.** Type "Buy stamps"; it goes to the Inbox (or today if Add was opened from Today). Picked from To fit in or the Inbox later.

## Monday morning

You open Today: classes as blocks, routine block if an agent made one, habit rings, To fit in with 4 to 7 things, From earlier with last week's leftovers. You decide which of the To fit in items to do and when, drag them into gaps, and give each a length. Habits have no time, so you decide when gym happens. An agent can do this planning for you if you ask it.

## When the day slips

Blocks stay where they were; you drag them or tap "Tomorrow" on each. "Close the day" in the evening moves everything left to tomorrow in one tap. Nothing reflows by itself.
