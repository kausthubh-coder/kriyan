What it means for the code

  • New: a planner in packages/core. Places coursework into work windows, keeps slack under the daily max, moves missed sessions forward.
  • Schema. Habits, routines and repeating tasks merge into one repeat; tasks gain prep hours and sessions; the profile gains work windows and a daily max.
  • Today. To fit in, From earlier and the plan sheet go; the one card and the moved-forward line arrive.
  • Phone. A live lock-screen card (iOS Live Activity, Android ongoing notification).
  • Agents. Moodle import and the extension email go through MCP, the same operations the app uses.
