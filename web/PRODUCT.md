# Product

## Register

product

## Users

One owner operates Kriyan across a browser and a paired personal agent node. They open Today to capture intent, see what the node is doing, and keep tasks and reminders current without managing infrastructure.

## Product Purpose

Kriyan turns plain-language intent into durable, inspectable work. This first slice succeeds when a command can be queued, handled by a paired node, and reflected as live activity plus a resulting reminder without a reload.

## Brand Personality

Grounded, capable, candid. The interface should feel calm under routine use and explicit about uncertainty, connectivity, and machine activity.

## Anti-references

- Chat-first shells that hide durable work behind a transcript.
- Decorative glass dashboards, neon AI gradients, and generic metric-card grids.
- Interfaces that imply an agent is working when a job is only queued or the node is offline.
- Broad second-brain navigation that distracts from Today, tasks, reminders, and activity.

## Design Principles

1. Lead with what needs attention now.
2. Make system state legible before making it beautiful.
3. Keep intent, execution, and durable results visibly connected.
4. Prefer familiar, keyboard-friendly product controls.
5. Reveal detail progressively without hiding failure or recovery actions.

## Accessibility & Inclusion

Target WCAG 2.2 AA contrast and semantics. Support keyboard-only operation, visible focus, reduced motion, zoom, phone and desktop layouts, and status communication that never relies on color alone.
